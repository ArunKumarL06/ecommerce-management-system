# E-Commerce Management System

## Overview

A full-stack E-Commerce Management System developed using Spring Boot, React, MySQL, and JWT Authentication.

The application provides secure user authentication, role-based authorization, product management, and REST APIs with Swagger documentation.

## Features

### Authentication & Authorization

* User Registration
* User Login
* JWT Authentication
* Role-Based Access Control (ADMIN / USER)

### Product Management

* Add Products
* Update Products
* Delete Products
* View Products
* Search Products

### Security

* Spring Security
* JWT Token Validation
* Protected APIs
* Password Encryption using BCrypt

### Database

* MySQL Database
* Spring Data JPA
* Hibernate ORM

### API Documentation

* Swagger UI
* OpenAPI Documentation

### Frontend

* React
* TypeScript
* Axios
* Responsive Design
* Modern UI

## Setup Instructions

### Backend

1. Configure MySQL database.
2. Update application.properties.
3. Run:

```bash
mvn clean install
mvn spring-boot:run
```

Backend URL:

```
http://localhost:8087
```

Swagger UI:

```
http://localhost:8087/swagger-ui/index.html
```

### Frontend

Install dependencies:

```bash
npm install
```

Run application:

```bash
npm run dev
```

Frontend URL:

```
http://localhost:3000
```
